  460: =head1 LIMITATIONS
  461: 
  462: =over 4
  463: 
  464: =item * No C<decode()> method exists to reverse C<encode()>.  Double-encoding
  465: is a real risk if C<encode()> is called on an already-encoded object.
  466: 
  467: =item * Language fallback is absent: if a requested language has no stored
  468: translation, C<undef> is returned rather than falling back to a related locale
  469: (e.g. C<en_GB> â†’ C<en>).
  470: 
  471: =item * The AUTOLOAD accessor silently ignores unrecognised method names that
  472: are not two-letter codes, returning C<undef>.  Typos in language codes produce
  473: no diagnostic.
  474: 
  475: =item * C<Object::Configure> support is best-effort; the exact semantics depend
  476: on the installed version and any project-level configuration that is present.
